# Basic HTML Website Portfolio

A central portfolio platform engineered to showcase architectural web design challenges, semantic HTML5 distribution, multi-page data tracking, and dynamic interactive client modules. This system aggregates multiple sub-projects, serving as an operational entry point for localized applications.

---

## Technical Challenges Overcame

To complete this core compilation milestone successfully, the implementation required solving data encapsulation problems, styling inheritances, dynamic DOM injection sequences, and conditional layout algorithms:

* **Asynchronous API Consumption and Rendering:** Configured runtime content pipelines in the MovieWeb engine using the standard Fetch API to extract metadata maps from external movie streaming directories (`TheMovieDB API`). The script dynamically creates structural cards inside loop routines (`forEach`), scaling interface items safely on runtime configurations.
* **Declarative DOM Architecture Optimization:** Refactored runtime structural nodes in `scropt.js` to construct centralized, flexible grid systems (`div_row`) outside of looping scripts. This mitigates heavy engine processing costs and eliminates layout stutter by applying layout fragments to the main content container (`#section`) as a single block insertion.
* **Data Scoped Finite State Engine:** Designed a data architecture in `index.js` mapping local game arrays (`monsters`, `locations`, `weapons`) directly to interface rendering properties. The game engine processes complex calculations asynchronously—handling hit rates (`Math.random()`), statistical mutations, and broken tracking components—updating visible DOM segments instantly through pointer assignments.
* **Strict Visual Flex Layout Boundaries:** Crafted responsive structural dividers using CSS Flexbox configurations across primary documents (`stylesheet.css`). Layout fields utilize targeted distribution directives (`margin-left: auto`, `justify-content: center`, and complex grid configurations) to perfectly divide distinct resume blocks, custom review elements, and application panels on arbitrary display matrices.

## Core Competencies Demonstrated

* **Functional JavaScript Automation:** Mastery of functional array iterations, dynamic document manipulation APIs (`createElement`, `appendChild`), operational event hooks, and algorithmic branch systems.
* **System Component Engineering:** Competence mapping logical code paths across different sub-directories (`JavaScript part`, `MovieWeb Project`, `Single-Page CV`) using structured component routing.
* **Modern Multi-Page Architecture:** Implementing cohesive visual design identities across distributed documents (`homePage.html`, `projectsPage.html`, `contactPage.html`, `articlesPage.html`) using a shared, external layout sheet.

## Application Features

* **Consolidated Project Navigation:** A responsive master hub managing distributed, clean references to a Single-Page CV, an interactive JavaScript RPG, and an API-driven Movie Catalog.

## Installation and Deployment

This repository serves as a localized multi-page environment containing basic client modules and local Node.js backend drafts.

### 1. Clone the Repository
Execute the git command inside your terminal (replace with your specific repository URL copied from GitHub):
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Switch to the project root folder:
```bash
cd "Basic HTML Website"
```

### 3. Review Sub-Module Configurations
The platform includes sub-modules requiring localized dependency maps (such as the `MovieWeb Project/BackEnd` server). Restoring those components requires standard node deployment routines:
```bash
cd "projects/MovieWeb Project/BackEnd"
npm install
```

### 4. Local Execution
* **Static Assets:** The main interface files can be evaluated directly by launching the `page/homePage.html` layout file via any modern web browser interface.
* **Live Development Server:** Open the root project repository directly in Visual Studio Code and leverage the **Live Server** plugin on `homePage.html` to navigate through all sub-projects cleanly with auto-reload activated.
