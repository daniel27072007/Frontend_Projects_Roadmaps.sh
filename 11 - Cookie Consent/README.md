# Cookie Consent and Tabs UI Component

A dual-purpose client-side interface featuring an interactive tabbed navigation module and a stateful cookie consent overlay banner. This application demonstrates asynchronous state persistence using browser storage APIs, declarative component styling transitions, and programmatic class manipulation via vanilla JavaScript.

---

## Technical Challenges Overcame

To complete this Roadmap.sh challenge successfully, the implementation required handling client-side persistence lifecycles, absolute layout layers, and declarative vector operations within the rendering pipeline:

* **Persistent State Lifecycle Integration:** Engineered a persistent authentication layer using the browser's native Web Storage API (`localStorage`). The evaluation loop parses existing tokens (`cookiesAceitos`) immediately during the script execution phase, conditionally adding target display modifiers (`cookieBoxClose`) to bypass banner rendering routines on subsequent application boot cycles.
* **Declarative Overlay Structural Layering:** Constructed an isolated notification prompt overlaying structural content layouts by implementing explicit coordinate spaces (`position: absolute`, `bottom: 40px`, `right: 40px`) paired with layer priority variables (`z-index: 2`). This isolates the alert window above base page landmarks.
* **Vector Vector Geometry via Pseudo-Elements:** Designed an accurate visual close trigger ('X') using clean CSS pseudo-elements (`::before` and `::after`) within an isolated relative box wrapper. The layout renders crisp intersections by applying centered displacement configurations combined with absolute geometric turns (`rotate(45deg)` and `rotate(-45deg)`).
* **Asynchronous Class Mutation Pipelines:** Attached explicit mouse callback routines (`onclick`) to action triggers to control visual rendering modes. Interaction with form elements toggles structural modifier rules, modifying layout transparency properties smoothly via target styling parameters (`opacity: 0` maps).

---

## Core Competencies Demonstrated

* **Client-Side Data Architecture:** Practical utilization of native key-value storage properties (`getItem`, `setItem`) to drive structural application layout states.
* **Modular JavaScript DOM Mapping:** Querying specific markup elements using precise selection parameters (`querySelector`) to capture input feedback loops.
* **Advanced Coordinate Styling:** Constructing modern floating overlay elements and complex geometric close buttons purely inside stylesheets without depending on graphic font libraries.

---

## Application Features

* **State-Persistent Consent Banner:** A floating compliance manager that evaluates user confirmation inputs and updates systemic view behaviors across browser sessions.
* **Tabbed Interface Framework:** Upper navigation modules separating structural layout blocks (First, Second, Third, and Fourth Tab options) with a highlighted active item.
* **Pure CSS Graphic Engineering:** Custom close actions utilizing vector rotation transforms rather than bulky external image files to optimize document download sizes.

## Installation and Deployment

This application operates completely as a client-side module using native browser execution models. No internal runtime packages or development servers are required.

### 1. Clone the Repository
Execute the git command inside your terminal (replace with your specific repository URL copied from GitHub):
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Switch to the project root folder:
```bash
cd "Cookie Consent"
```

### 3. Local Execution
You can evaluate this application using standard local browser rendering workflows:
* **Direct Browser File Launch:** Locate the root project directory via your file browser and double-click the `index.html` file to boot the layout view inside any browser platform.
* **VS Code Hot-Reload Deployment:** Load the repository inside Visual Studio Code, activate the **Live Server** extension, and choose **Open with Live Server** to access the view within a local development channel.
