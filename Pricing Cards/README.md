# Pricing Cards Component

A responsive, asymmetric pricing matrix interface engineered to present subscription tiers cleanly using advanced layout operations. This implementation showcases precise flex alignment fields, custom vector generation using pseudo-elements, and fluid hovering state physics built entirely through semantic HTML5 structure and raw stylesheet parameters without loading script packages or graphics fonts.

---

## Technical Challenges Overcame

To complete this Roadmap.sh challenge successfully, the implementation required handling dynamic container scaling hierarchies, coordinate-scoped indicator boxes, and complex procedural drawing maps inside the styling layer:

* **Visual Hierarchy via Asymmetric Scaling:** Engineered a targeted focal matrix using two distinct document styling classes (`.focusCard` and `.normalCard`). By applying variable dimension metrics (`height: 580px` versus `550px`) and linking layout structures to bottom bounds (`align-items: end`), the layout naturally scales the core tier above standard options, driving fast, conversions.
* **Coordinate-Bound Dynamic Ribbon Overlays:** Fabricated a prominent contextual header badge ("Most Popular") natively using absolute pseudo-elements (`.focusCard::after`). The banner maps precise coordinates (`top: -25px`, `left: 50%`) and isolates centering metrics by incorporating precise structural offsets (`transform: translateX(-50%)`) to guarantee balanced placement above standard elements.
* **Pure CSS Checkmark Vector Generation:** Designed custom feature bullet checks cleanly using unified pseudo-elements (`::before` and `::after`) attached directly to standard paragraphs (`#listItem`). The layout constructs a crisp check icon by using absolute box shapes wrapped with border clipping parameters and explicit turns (`transform: rotate(-45deg)`).
* **Taxing Micro-Interaction Feedback Rules:** Programmed distinct tactile responses inside primary button layers (`#button`) by executing clean tracking parameters (`transition: all 0.3s`). Hovering states manipulate color parameters seamlessly (`rgb(255, 235, 120)` maps) based on tier type, supplying users with native app interactivity feedback.

## Core Competencies Demonstrated

* **Advanced Multi-Card Grid Structuring:** Competence aligning asymmetric component rows cleanly using CSS Flexbox layout tools and proportional grid buffers.
* **Pseudo-Element UI Engineering:** Structuring crisp visual iconography, highlights, and custom symbols entirely through text constraints to cut document rendering weights down.
* **Defensive Stylesheet Implementation:** Enforcing strict box configuration limits (`box-sizing: border-box`) alongside reset commands to lock layout integrity across browser rendering engines.

---

## Application Features

* **Three-Tier Subscription Architecture:** An isolated price container displaying basic, premium, and business packages alongside scaled data lists.
* **Prominent High-Contrast Visual Focus:** Custom accent overlays and matching highlights drawing attention to the most popular conversion track.
* **Reactive Core Button Fields:** Polished action controls featuring transition parameters that trigger custom colors upon mouse hover events.

## Installation and Deployment

This application operates completely as a client-side layout component using native browser parsing engines. No framework setups or development server installations are required.

### 1. Clone the Repository
Execute the git command inside your terminal (replace with your specific repository URL copied from GitHub):
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Switch to the project root folder:
```bash
cd "Pricing Cards"
```

### 3. Local Execution
You can evaluate this application using standard local browser rendering workflows:
* **Direct Browser File Launch:** Access the local project folder using your operating system file locator and double-click `index.html` to run the tier matrix layout inside any browser window.
* **VS Code Server Tooling:** Open the application root folder inside Visual Studio Code, activate the **Live Server** extension tool, and select **Open with Live Server** to access the layout canvas under an automated development channel.
