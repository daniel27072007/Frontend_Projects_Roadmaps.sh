# Testimonial Cards Component

A responsive web page presenting a collection of structured card components engineered to display customer endorsements across various presentation variants. This project showcases spatial composition techniques, custom procedural vector transformations, and vector mask manipulation implemented purely using semantic HTML5 structures and clean CSS layout mechanics.

---

## Technical Challenges Overcame

To complete this Roadmap.sh challenge successfully, the implementation required solving speech balloon mapping parameters, vector layout masking, dynamic border-clipping, and absolute alignment properties:

* **Pure CSS Chat Balloon Vector Generation:** Engineered a seamless declarative speech bubble pointer natively using borders (`#reviewBox1::after`). The vector handles directional paths cleanly by matching a solid top border color to the card background, clipped against transparent parameters to push a precise triangular wedge directly underneath the layout box.
* **Asymmetric Layer Alignment Formats:** Programmed flexible component flows across distributed layout matrices (`.testimonials1` and `.testimonials2`). The matrix uses multi-tier distribution configurations, enabling upper items to spread horizontally via explicit flex distribution rules while trailing segments line up vertically to handle variable card scales.
* **Complex Multi-Asset Carousel Accents:** Fabricated a precise visual author switcher widget inside review wrappers (`.authorSidebar`). The carousel layout layers faded, lower-priority asset frames (`opacity: 30%`) adjacent to the centered profile container, framed neatly by directional arrows drawn procedurally with border flips (`transform: rotate()`).
* **Circular Media Frame Clipping:** Resolved aspect ratio distortion on mixed resolution profile graphics (`.jpg` and `.avif`) by applying strict bounding shapes (`aspect-ratio: 1/1`) combined with object coverage filters (`object-fit: cover`). This guarantees crisp circular assets across desktop layouts without scaling flaws.

---

## Core Competencies Demonstrated

* **Advanced Layout Design Orchestration:** Competence structural programming with CSS Flexbox layouts using alternating path lines (`flex-direction: row` versus `column`) to align diverse modules cleanly.
* **Procedural Graphic Masking:** Building complex geometric shapes, custom rating stars, and floating speech pointers purely within style declarations to optimize asset download steps.
* **Defensive Element Sizing:** Enforcing strict property rules (`box-sizing: border-box` alongside automatic sizing) to prevent parent element borders from breaking layout frameworks.

---

## Application Features

* **Varied Endorsement Matrix:** A library of card styles mapping text blocks alongside custom graphic avatars, rating modules, and floating containers.
* **Tactile Rating Star System:** An active rating interface built through structured horizontal image arrays to cleanly capture high-grade performance tokens.
* **Symmetrical Layout Wireframes:** Clean dividing borders segmenting structural page content seamlessly to prevent layout collisions on large desktop resolutions.

## Installation and Deployment

This application operates completely as a client-side layout component using native browser parsing engines. No package dependencies or dev server architectures are required.

### 1. Clone the Repository
Execute the git command inside your terminal (replace with your specific repository URL copied from GitHub):
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Switch to the project root folder:
```bash
cd "Testimonial Cards"
```

### 3. Local Execution
You can evaluate this application using standard local browser rendering workflows:
* **Direct Browser File Launch:** Access the application directory via your operating system file manager and double-click the `index.html` file to run the testimonials showcase inside any browser.
* **VS Code Live Server Utility:** Open the directory inside Visual Studio Code, ensure the **Live Server** plugin is active, and select **Open with Live Server** to access the view within an automated local host channel.
